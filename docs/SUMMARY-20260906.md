## 1. 架构（A 主线，定稿 v0）
单状态 h、无残差无 FFN，CfC 液态门折进 SSM：
```
z_t = SiLU(Wz·conv(x))                      # 内容候选（conv kernel=4 短记忆）
Δ_t = softplus(Wd·x + bd)                   # 输入相关步长
a_t = exp(−Δ_t·exp(A_log))                  # 每通道液态保留门(CfC 时间常数)
h_t = a_t·h_{t-1} + (1−a_t)·z_t             # 单状态收敛-写
y_t = Wr·LN(h)·scale + dv⊙x                 # 读：状态 + 当前字节直通(D·x, 关键)
```
- 状态=激活非参数；历史**不 detach**，窗内全梯度；f64 分块 scan(并行)
- 关键修复：d_bias 负初值；f64 chunk 防 exp 溢出；**D·x 读直通破 4.10 平台**

## 2. 实验结论（全部可复现）
| 项 | 结果 | 结论 |
|---|---|---|
| EMA(同位置蒸馏) | 大配置 eval 3.53 vs A 1.795 | **否**，伤语言建模 |
| Sketch(旁路读,自相似) | recall≈噪声、零增量 | **否**，且"数据库式"违背无仓库哲学 |
| 纯随机绑定 recall | A/B/C/D 全≈噪声 | 该协议测"数据库记忆"，非本哲学目标(待换"复用塑形") |
| **A 单线** dim512/6.5M | eval 1.795 | 破 volume 2.958 |
| **A 单线** 68M (D1280/L14) | **final eval 1.2782**(16000步/98M tok/42min) | 同域跌破 2-gram 大幅 |
| carry 跨窗 | dim256~0 → 6.5M −0.009 → **68M −0.019** | 跨窗记忆随规模增强 |
| BPB | 1.844 bits/byte ≈ 4-gram 熵 | 有效视界≈4字节(conv4)；低阶吃满，瓶颈=长程 |

## 3. 生成/解码诊断
